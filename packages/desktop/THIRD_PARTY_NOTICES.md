# Avisos de software de terceiros — Pink Logic Desktop

## FFmpeg (Cortes Virais)

O instalador inclui um executável do **FFmpeg**, distribuído através do pacote npm
`ffmpeg-static` (versão 5.3.0, licença **GPL-3.0-or-later**), usado só para cortar vídeo,
extrair áudio e queimar legendas. O FFmpeg corre como programa separado; o resto do Pink Logic
não é uma obra derivada dele.

- Executável: `resources/app.asar.unpacked/node_modules/ffmpeg-static/`
- Texto da licença do pacote: `resources/app.asar.unpacked/node_modules/ffmpeg-static/LICENSE`
- Código-fonte do pacote: https://github.com/eugeneware/ffmpeg-static
- Código-fonte do FFmpeg: https://ffmpeg.org/download.html#get-sources

Quem recebe o Pink Logic pode obter o código-fonte do FFmpeg nos endereços acima.
